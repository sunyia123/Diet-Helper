# OpenMoji food subset

165 unmodified color SVGs from **OpenMoji 17.0.0**, by the OpenMoji contributors.

- Upstream: https://github.com/hfg-gmuend/openmoji
- Project: https://openmoji.org/
- Artwork license: **CC BY-SA 4.0**, full text in `LICENSE.txt`.
- Source package pinned to https://unpkg.com/openmoji@17.0.0/
- Includes food/drink, special food illustrations, and animal/plant symbols useful for ingredients.
- Generated by `scripts/fetch-openmoji-food-icons.mjs`; Chinese labels and search groups are maintained there.

All assets are local. No runtime CDN, image upload, or external image lookup is required. Original Twemoji assets in the parent folder remain for compatibility. Text and user photos keep their existing behavior.
